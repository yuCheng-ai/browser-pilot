# 路线图

## 阶段 0：项目基线

- 固定目录结构、模块边界和安全原则。
- 初始化桌面端、服务端和共享包工作区。
- 建立格式化、类型检查、测试和构建命令。

## 阶段 1：最小浏览器 Agent

- 在 Playwright 适配层打通打开页面、点击、输入、滚动、等待和截图。
- 建立 `browser-core` 统一动作接口。
- 建立本地服务任务 API 和桌面端任务控制台。
- 记录步骤、截图、URL、失败原因和最终报告。
- 支持访问本地开发站点做基础验收。

## 阶段 2：页面理解和提取

- 输出 DOM 摘要、Accessibility Tree 摘要和可交互元素列表。
- 提供结构化提取规则和页面文本抽取。
- 增加任务步骤校验、重试和超时策略。
- 增加可读的任务运行报告和证据引用。

## 阶段 3：录制回放和登录态

- 捕获用户操作生成流程。
- 支持流程参数、等待条件和回放结果。
- 管理本地 profile、cookie 和会话隔离。
- 对后台系统常见表单、列表和筛选任务提供稳定性增强。

## 阶段 4：安全和适配扩展

- 完善支付、删除、提交、导出、上传和批量操作的风险策略。
- 接入 Chrome CDP 场景能力。
- 接入 OpenAI 和 Ollama 模型适配。
- 为代码验收和竞品调研提供场景扩展。

## 阶段 5：增强能力

- 接入视觉理解能力，补足 DOM 信息不足的页面。
- 支持更强的流程分支、断点恢复和任务复跑。
- 支持更丰富的报告导出和团队内分享格式。
