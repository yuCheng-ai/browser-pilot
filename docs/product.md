# 产品定义

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 项目名 | BrowserPilot |
| 中文名 | 浏览器领航员 |
| 目录名 | `browser-pilot` |
| 定位 | 本地浏览器 Agent 客户端 |

## 一句话说明

BrowserPilot 在本机浏览器环境中理解页面、执行网页任务、复用操作流程，并把每次执行过程沉淀为可审计的任务记录和报告。

## 目标用户

- 需要在业务后台重复执行网页操作的运营、客服和实施人员。
- 需要验证本地 Web 项目的研发和测试人员。
- 需要在多个网页中采集、对比和整理资料的研究人员。
- 需要在登录态页面执行自动化任务，但不希望把浏览器状态交给远端服务的个人或团队。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 浏览器自动操作 | 打开页面、点击、输入、滚动、等待、截图和读取页面状态。 |
| 网页任务执行 | 把自然语言任务或结构化任务拆成多步骤动作并持续校验结果。 |
| 网页数据提取 | 从 DOM、Accessibility Tree、页面文本和截图快照中抽取结构化信息。 |
| 流程录制回放 | 记录用户操作步骤，生成可编辑和可重放的流程。 |
| 登录态任务执行 | 使用本地浏览器 profile、cookie 和会话状态完成授权页面任务。 |
| 本地项目自动验收 | 访问本地开发服务，执行验收步骤，汇总截图、日志和结论。 |
| 业务后台自动操作 | 面向表单、列表、筛选、审批、导入导出等后台工作流。 |
| 竞品和资料自动调研 | 搜索、浏览、提取、对比并汇总公开网页资料。 |

## 首版范围

- 提供桌面端任务入口和本地服务。
- 先接入 Playwright，保留 Chrome CDP 适配边界。
- 支持最小动作集：`open`、`click`、`type`、`scroll`、`wait`、`screenshot`、`extract`。
- 支持任务执行记录、截图快照、页面快照和报告输出。
- 对登录、支付、删除、提交和跨站敏感数据读取建立安全拦截。
- 先让录制和回放覆盖稳定的线性流程，再扩展条件分支和重试策略。

## 非目标

- 首版不把 BrowserPilot 定位成云端 RPA 平台。
- 首版不承诺绕过验证码、反爬限制、企业安全策略或站点服务条款。
- 首版不默认替用户执行不可逆交易、批量删除或高风险提交。
- 视觉模型接入可以后置，首版页面理解优先基于 DOM、Accessibility Tree 和截图留档。

## 成功标准

- 用户可以在桌面端发起一个浏览器任务，并看到完整执行过程。
- 同一登录态任务可以在本地 profile 中稳定执行，且敏感状态不被写入源码仓库。
- 高风险动作在执行前被识别、拦截或要求明确确认。
- 每次任务执行都能回溯输入、动作、快照、提取结果和最终报告。
